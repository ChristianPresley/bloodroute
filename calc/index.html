V Rising caster calculator

Simulates a single-target boss fight (spells, Veils, ultimates and the crossbow) and searches for the highest-damage loadout per game stage. DPS (mix) averages 90/180/300/600-second fights, ± its standard error over the random seeds. Assumptions are in engine.js (ASSUME).

Each run takes several minutes (late game ~10). Served over http (e.g. npx http-server calc) it runs in a background worker; opened as a local file it runs on the page and the tab freezes until it finishes. Command line: node calc/run.js late. Top damage sources are from the 600 s fights.
